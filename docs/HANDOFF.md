## 1. 這個專案在做什麼

老師每週上 Scratch 3 遊戲程式課。每一課，老師會給一個 `.sb3`（通常改編自別的教學網站），要做出一份**給學生看、也能上課投影的教學網頁**，並把它加進這個網站。網站首頁要能看到：

- 每一課的連結、簡介、課程來源、**這單元的新積木**
- **技能統整（累計）**：從第一課到最新一課，學生總共學會哪些積木、操作與觀念

## 3. 老師的教學原則（最重要）

1. **對象**：第一次接觸 Scratch 的國小四年級。
   - 不教 x/y 座標（學生不懂）：位置用「拖到舞台上」、方向用「點方向數字轉轉盤」。
   - 先不用「隨機取數」。
   - 選最簡單的寫法。例：開槍 = `當角色被點擊 → 造型換成 造型2 → 等待 0.2 秒 → 造型換成 造型1`，**不要**用 `如果 <滑鼠鍵被按下？>` + `等待直到 <<滑鼠鍵被按下？> 不成立>`（老師說太難）。
2. **學過 vs 新的**
   - 學過的（`skills.js` 裡課次比這課早的）→ 只給積木圖＋一句說明，步驟標題旁加 `<span class="chip old">學過，直接照著拼</span>`。
   - 新積木 → 一步一步教，積木圖用 `hl:1`（黃框＋「新」），六角形條件用 `nw:1`，文字裡加 `<span class="nb">新</span>`。
3. **重點步驟給現成素材**，讓步驟聚焦在新技能。例：準心的造型1 直接給 `.sprite3`，步驟只教「複製造型＋填滿工具塗紅」。
   - **繪畫類素材做成向量（SVG）**，老師在向量模式教填滿工具。封閉形狀內放 `fill-opacity:0.01` 的填色，填滿工具點一下就能整塊上色；線條放在形狀上面。
4. **管整場遊戲的程式放同一段、同一個角色**。例：月球打老鼠的「分數歸零＋時間設為 30＋每秒 −1＋時間 = 0 停止全部」寫在準心一段。加分則留在被打的角色身上（只有它知道自己被打中）。
5. **關鍵積木要寫「如果少了它會怎樣」**（對照表），並在成品預覽加「示範」勾選框讓全班看差別。例：老鼠的「隱藏 → 等待 1 秒 → 顯示」。
6. **每課都要有可以玩的成品預覽**（用 sb3 裡的原圖，JS 模擬 30fps 的程式邏輯）。
7. **課程來源**一定要標。
8. **完成版 sb3 不上網站**。

老師溝通風格：指令很短、期待你直接做完，不用一直問。完成後簡短回報做了什麼、網址。

## 4. 標準教學頁格式（以 moon-mole.html 為例）

### 4.1 版面
```
頁首：eyebrow（SCRATCH 3 · 資訊課 · 四年級 · 第一次接觸 Scratch）
      h1 課名 + <small>副標</small>
      <p class="credit">課程內容修改自 <a>來源</a></p>
      chips：建議節數、角色數／程式段數；「投影模式」按鈕
分頁列（.tabbar）：教學步驟｜技能統整（累計）
#tabLesson
  .hero：左＝可玩預覽（.stage 480×360 內部座標，綠旗／停止、分數時間 monitor、示範勾選）
         右＝這個遊戲學生會學到（ol）＋ 節次表（.timeline）
  nav.steps：黏在上方的步驟導覽（由 JS 依 section 自動產生，分組用 data-g）
  .part 分段標題 + section.step（id="s0"…）
#tabSkills：技能統整快照
footer：課名 · vX.Y · 日期 ｜ 課程修改自 …
.pbar：投影模式的上一步／下一步
```

### 4.2 步驟 section 兩種寫法
- **詳細步驟（新技能）**：`<section class="step" id="sN" data-t="導覽短名" data-g="分組">` → `.shead`（`.num`、`h2`、`.chip` 分鐘）→ `.cols`（左 `.how` 的 `<ol>`＋`.note`，右 `.fig` 的 `<figure class="blocks"><div data-script="名稱"></div></figure>`）
- **學過，只給程式**：`<section class="step quick" ...>` → `.shead`（多一個 `.chip.old`）→ `p.goal` → `.qgrid` 放積木圖 → 若有新積木加 `.note.tip.newb`

提示框：`.note.tip`（黃，說明為什麼）、`.note.warn`（紅，先確認／常見卡關）、`.note.check`（綠，檢查點／觀察）。

固定的收尾步驟：**除錯表**（`table.debug`：看到的狀況／可能原因／怎麼修）、**挑戰**（`.lv` 三欄 ★☆☆～★★★）、**存檔**（檔名 `課名_座號姓名.sb3` ＋ 下課前確認清單）。

### 4.3 頁面裡的 JS（都在最後一個 `<script>`）
- `IMG`：base64 圖片（角色、背景）。
- 積木產生器（同 `assets/scratch-blocks.js`）。
- `SCRIPTS`：每段程式的積木資料，HTML 用 `data-script="key"` 取用。
- `FIGS`：自畫的 SVG 示意圖（編輯器畫面、繪畫工具、滴管、複製角色、反彈…），HTML 用 `data-fig="key"`。紅框編號用 `CO('①',x,y,w,h)`。
- 成品預覽 IIFE：`tick()` 每 1/30 秒執行一次，照 sb3 的程式邏輯模擬（移動、反彈、碰到判斷、計時、停止全部）。
- 步驟導覽＋投影模式 IIFE（←→ 翻頁、Esc 離開）。
- 技能統整 IIFE（同 `assets/skills.js`）。

### 4.4 視覺規則
- 顏色全部用 CSS 變數（`:root` 淺色，`prefers-color-scheme: dark` 與 `[data-theme]` 深色），不要寫死只適用一種主題的顏色。
- 字型：標題 LXGW WenKai TC、內文 Noto Sans TC、數字 JetBrains Mono（Google Fonts）。
- 手機寬度（~400px）不能左右捲動；窄螢幕 `.cols` 變一欄。

## 5. 積木產生器 `assets/scratch-blocks.js`

```js
renderScript([
  {t:'hat', c:'event', p:['當',{flag:1},'被點擊']},
  {t:'s',   c:'looks', hl:1, p:['圖層移到',{dd:'最上'},'層']},          // hl:1 = 新積木
  {t:'c',   c:'control', cap:1, p:['重複無限次'], in:[                // C 型，cap:1 = 下面不能再接
     {t:'s', c:'motion', p:['定位到',{dd:'鼠標'},'位置']}
  ]}
])
```
- `t`：`hat` 帽子／`s` 一般／`c` C 型（`in` 放嘴巴裡的積木）
- `c`：`event motion looks sound control sensing operators data`
- 參數：`{n:'10'}` 數字框、`{dd:'鼠標'}` 下拉、`{flag:1}` 綠旗、`{color:'#f80000'}` 色塊、`{bool:{c,p,nw}}` 六角形、`{rep:{c,p}}` 圓角報告積木
- 「停止 全部」用 `{t:'s',c:'control',cap:1,p:['停止',{dd:'全部'}]}`
- 變數報告積木：`{rep:{c:'data',p:['時間']}}`
- 文字寬度是估算的（中文 14.5、英數 8.3、空白／符號 5）；若英文字太擠可微調 `tw()`。

## 7. 技能統整資料 `assets/skills.js`

最上面是資料，下面是渲染。要改的只有資料區：

```js
const LS=[                       // 課次，依時間順序；最後一筆 = 最新一課（自動標紅、成為「最新一課新學」）
  ['l1','小狗追球','9/29','Scratch STEAM 教學'],
  ...
  ['l5','月球打老鼠','四年級','阿玉的 Scratch 教學網']
];
const ALL=[                      // [分類, 顏色, [[積木, 用途, 課次代號, (最新一課才填：用在第幾步)], ...]]
  ['事件','#FFBF00',[[H,'按下綠旗時開始執行','l1'], ...]],
  ...
];
const OPS=[[課次, '操作技能'], ...];      // 不是積木的操作，如「用填滿工具上色」
```

## 8. 新增一課的完整流程

1. **拿到 sb3** → 解壓到新資料夾，`python3 -I tools/sb3_dump.py 資料夾/project.json` 看每個角色的程式。
2. **找問題**：按住滑鼠可連發？角色名稱多空白／下拉選到不存在的角色（例「Cat 2」）？迴轉方式造成倒立？角色重複複製？遊戲不會結束？用了座標或隨機（四年級要拿掉）？
3. **修正完成版 sb3**（直接改 project.json 再 zip 回去），用 `node tools/sb3_run.js 檔案.sb3 35` 確認能載入、計時正常。完成版**交給老師，不放 repo**。
4. **對照 `assets/skills.js`**，列出這課哪些積木是新的、哪些學過。
5. **先給老師大綱**（除非老師說直接做）：學生會學到、步驟清單（標學過／新）、節數。
6. **做教學頁**：複製 `moon-mole.html` 為新檔（英文小寫檔名，如 `space-shooter.html`），替換：頁首、`IMG`、`SCRIPTS`、`FIGS`、成品預覽邏輯、所有 section、除錯表、挑戰、存檔、頁尾、技能統整快照（或改成 `<script src="assets/scratch-blocks.js">`＋`assets/skills.js` 直接讀共用資料，更好維護）。
   - 檔案很大（base64 圖片），用 Python 字串取代來改，不要整檔重寫。
   - 角色圖從 sb3 取出；背景照片先縮到 480×360 JPEG 再 base64。
7. **更新 `assets/skills.js`**：LS 加一筆（成為最新）、ALL 加新積木（第 4 欄填步驟）、OPS／IDEAS 加新項目。
8. **更新 `index.html`**：課程列表加一張卡片（`data-ls`、課名連結、日期／對象、簡介、來源、素材下載連結），頁尾版本號 +0.1、日期更新。
9. **素材**放 `files/`，檔名帶版本與日期。
10. **檢查**：用 Playwright 截圖桌面與手機寬度，看積木圖有沒有擠字、示意圖紅框位置、主控台有沒有錯誤；兩個分頁都點一次。
11. **commit & push**（commit 訊息用繁中，例：「新增第 5 課 太空射擊」）。Pages 約 1～2 分鐘更新。
12. 回報老師：新頁網址、首頁網址、這課新積木、需要老師實測的部分（碰到／點擊類判斷無法無畫面測試）。

## 10. 過去做過的決定（避免重來）
